# PlushCare

> PlushCare is a direct-to-consumer telehealth and virtual primary care service that connects
> patients in all 50 US states with board-certified physicians for online doctor visits, available
> 24/7. Founded in 2014 in San Francisco by Dr. James Wantuck and Ryan McQuaid. Effective
> 2026-07-31, PlushCare, Inc. is a Delaware corporation and a subsidiary of Fabric Labs, Inc.;
> it was previously acquired by Accolade (2021), which Transcarent acquired (2025).

**PlushCare publishes no public API.** There is no developer portal, no API reference, no
OpenAPI/AsyncAPI/GraphQL contract, no SDK, no MCP server and no agent card. This file was
GENERATED by the API Evangelist enrichment pipeline from the repo's own probed artifacts so an
agent can stop looking, rather than harvested from a provider-served /llms.txt (plushcare.com/llms.txt
returns 404).

## What exists

- Marketing site: https://plushcare.com/ (HubSpot CMS, 1,095 URLs in sitemap, mostly condition
  and medication landing pages plus a health blog)
- Patient application: https://my.plushcare.com/ (Next.js single-page app; booking flow at
  /booking/primary-care/method/, login at /login)
- Application backend: https://api.plushcare.com/ (Django REST Framework, HTTP 200, returns
  `{"users": "https://api.plushcare.com/users/"}`). This is the consumer app's own private
  backend, NOT a published product. The single advertised collection returns HTTP 403
  `{"detail": "You do not have permission to perform this action."}` anonymously, and every
  schema path — /openapi.json, /swagger.json, /schema/, /api/schema/, /docs, /redoc,
  ?format=openapi — returns 404.

## Pricing (patient, not developer)

- PlushCare Membership: $19.99/month, first month free. Unlimited Care Team messages,
  appointments in as soon as 15 minutes, prescription discount card, lab discounts, free
  family memberships, cancel anytime.
- Visit with in-network insurance: most patients pay $30 or less.
- Visit without insurance: $129 initial visit.
- Medication and lab costs are not included in the membership.
- Source: https://plushcare.com/membership
